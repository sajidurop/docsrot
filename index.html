How it works

Enter a docs URL (CORS-enabled sites) or paste its HTML. DocsRot checks every link live, flags broken ones, and flags pages whose content references old years against your staleness rule.

Data is stored only in your browser (localStorage) unless a feature explicitly fetches a URL or API you enter. Run npm start for the real server — live checks run server-side and history is saved on disk. Opening index.html directly still works in browser-only mode.
